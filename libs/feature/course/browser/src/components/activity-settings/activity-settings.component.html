Gestion de l'activité

Actions avancées

Fermer l'activité

Les étudiants ne pourront plus accéder à cette activité.

Rouvrir pour tous

La date de fin sera automatiquement supprimée.

Recharger l'activité

L'activité sera remplacée par sa dernière version publiée.

Supprimer l'activité

Cette action est irréversible.

Attention - Première période d'accès

En ajoutant cette période :

  • Seuls les utilisateurs/groupes spécifiés auront accès
  • Les autres membres perdront l'accès à l'activité
  • Vous pourrez modifier ces restrictions plus tard
💡 Conseil : Pour que les membres non spécifiés gardent l'accès, créez une période supplémentaire avec le type "Tous les autres".
