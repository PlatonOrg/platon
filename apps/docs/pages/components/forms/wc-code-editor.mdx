# CodeEditor

`wc-code-editor`

Éditeur de code complet avec coloration syntaxique pour multiples langages de programmation, indentation automatique et suggestions. Adapté aux exercices d'informatique comme la programmation, le débogage, la complétion de code, les algorithmes, ou l'analyse de code avec une interface professionnelle similaire aux IDE modernes.

## Documentation

Le composant CodeEditor offre un environnement d'édition de code complet directement intégré dans vos exercices PLaTon. Il dispose de fonctionnalités essentielles qu'on retrouve dans les IDE modernes, rendant l'expérience de programmation agréable et productive pour les apprenants.

### Caractéristiques principales

- **Coloration syntaxique** pour de nombreux langages de programmation
- **Indentation automatique** qui s'adapte selon le langage utilisé
- **Numérotation des lignes** pour une référence facile
- **Suggestions de code** (auto-complétion) qui peuvent être activées ou désactivées
- **Hauteur personnalisable** pour s'adapter à vos besoins de mise en page
- **Décorations** pour signaler une ligne ou une plage de code problématique

### Langages supportés

Le composant prend en charge un large éventail de langages de programmation, notamment Python, JavaScript, Java, C, C++, HTML, CSS et bien d'autres. Spécifiez simplement le langage souhaité via la propriété `language`.

### Cas d'utilisation

Le CodeEditor est parfait pour:

- Des exercices de programmation où les apprenants doivent écrire du code complet
- Des activités de débogage où un code avec des erreurs est présenté
- Des exercices à trous où certaines parties du code doivent être complétées
- Des démonstrations interactives avec du code modifiable

### Décorations

La propriété `decorations` accepte une liste de lignes ou de plages à signaler. Les numéros de ligne et de colonne commencent à 1. Une icône apparaît dans la gouttière au début de la ligne ; `severity` choisit l'icône (`error`, `warning` ou `info`) et `message` affiche un texte au survol. Pour surligner également un élément précis, fournissez les colonnes de début et de fin.

Les décorations représentent les résultats du diagnostic du code courant : elles sont effacées dès que l'élève modifie le code. Le parent peut les recalculer et fournir une nouvelle liste après son évaluation.

```json
{
  "code": "total = price * quantity",
  "decorations": [
    {
      "startLineNumber": 1,
      "severity": "error",
      "message": "Vérifiez le calcul du total"
    },
    {
      "startLineNumber": 1,
      "startColumn": 9,
      "endColumn": 14,
      "severity": "warning",
      "message": "Cette valeur doit être vérifiée"
    }
  ]
}
```

### Conseil d'utilisation

Pour une expérience optimale, adaptez la hauteur de l'éditeur en fonction de la quantité de code attendue, et activez les suggestions uniquement lorsque c'est pédagogiquement pertinent.

<summary>Fonction JavaScript testée</summary>

`````ple
sandbox = "node"

editeur = :wc-code-editor
editeur.language = "javascript"
editeur.height = 220
editeur.code ==
function somme(tableau) {
  // Écrivez votre code ici
}
==

title ==
Somme des éléments d'un tableau
==

statement ==
Complétez la fonction `somme(tableau)` pour qu'elle **renvoie** la somme des nombres du tableau.
Un tableau vide a pour somme `0`.
==

form ==
{{ editeur }}
==

grader == #!lang=js
const tests = [[[1, 2, 3], 6], [[], 0], [[-4, 4, 10], 10], [[2.5, 2.5], 5]]
const resultats = []
let reussis = 0

// Signale dans l'éditeur les lignes qui affichent au lieu de renvoyer.
const decorations = []
editeur.code.split('\n').forEach((ligne, i) => {
  if (ligne.includes('console.log')) {
    decorations.push({
      startLineNumber: i + 1,
      severity: 'warning',
      message: 'La fonction doit renvoyer le résultat avec return, pas l\'afficher.',
    })
  }
})
editeur.decorations = decorations

let somme
try {
  somme = new Function(editeur.code + '\nreturn somme')()
} catch (e) {
  somme = undefined
  resultats.push({ name: 'Compilation', type: 'error', description: String(e), display: true })
}

if (typeof somme === 'function') {
  for (const [entree, attendu] of tests) {
    let obtenu
    try {
      obtenu = somme([...entree])
    } catch (e) {
      obtenu = 'Erreur : ' + e.message
    }
    const ok = obtenu === attendu
    if (ok) reussis++
    resultats.push({
      name: `somme(${JSON.stringify(entree)})`,
      type: ok ? 'success' : 'error',
      arguments: JSON.stringify(entree),
      expected: JSON.stringify(attendu),
      obtained: JSON.stringify(obtenu) ?? 'undefined',
    })
  }
}

grade = Math.round((100 * reussis) / tests.length)
// Un feedback dont le contenu est une liste est affiché sous forme de feedbacks dépliables.
feedback.type = grade === 100 ? 'success' : 'error'
feedback.content = resultats
==

solution ==
```js
function somme(tableau) {
  let total = 0
  for (const x of tableau) total += x
  return total
}
```
==
`````

`````ple
sandbox = "python"

editeur = :wc-code-editor
editeur.language = "python"
editeur.height = 200
editeur.code ==
def maximum(liste):
    # Écrivez votre code ici
    pass
==

title ==
Maximum d'une liste (Python)
==

statement ==
Écrivez la fonction `maximum(liste)` qui renvoie le plus grand élément d'une liste non vide,
**sans utiliser** la fonction prédéfinie `max`.
==

form ==
{{ editeur }}
==

grader == #!lang=py
import random

tests = [[3, 1, 2], [-5, -2, -9], [7]]
tests.append([random.randint(-50, 50) for _ in range(8)])

details = []
reussis = 0
espace = {}

try:
    exec(editeur["code"], espace)
except Exception as e:
    details.append({"name": "Exécution du code", "type": "error", "description": repr(e), "display": True})

fonction = espace.get("maximum")
if "max(" in editeur["code"]:
    details.append({"name": "Contrainte", "type": "warning", "description": "La fonction max est interdite."})
elif callable(fonction):
    for liste in tests:
        try:
            obtenu = fonction(list(liste))
        except Exception as e:
            obtenu = repr(e)
        ok = obtenu == max(liste)
        reussis += 1 if ok else 0
        details.append({
            "name": f"maximum({liste})",
            "type": "success" if ok else "error",
            "expected": str(max(liste)),
            "obtained": str(obtenu),
        })

grade = round(100 * reussis / len(tests))
feedback["type"] = "success" if grade == 100 else "error"
feedback["content"] = details
==
`````
