# MatchList

`wc-match-list`

Composant interactif permettant d'associer des éléments entre deux colonnes en traçant des lignes. Parfait pour les exercices d'appariement comme associer des termes à leurs définitions, des mots à leurs traductions, des formules à leurs applications, ou encore des images à leurs descriptions.

## Documentation

Le composant MatchList permet de créer des exercices interactifs d'appariement où les apprenants doivent établir des correspondances entre des éléments disposés dans deux colonnes distinctes. Il s'utilise typiquement en créant un ensemble d'éléments sources (colonne de gauche) et cibles (colonne de droite) que l'apprenant relie par des traits.

### Organisation des éléments

Le composant s'articule autour de deux collections principales:

#### Éléments à relier (`nodes`)

Chaque élément est défini par un objet avec trois propriétés essentielles:

```typescript
{
    "id": string, // Identifiant du noeud.
    "type": "source" | "target", // Type du noeud.
    "content": string, // Contenu en markdown.
}
```

#### Connexions entre éléments (`links`)

```typescript
{
    "source": string, // Identifiant du noeud source.
    "target": string, // identifiand du noeud cible.
    "css"?: string, // Voir API CSS.
}
```

Les éléments de type source apparaissent dans la colonne gauche, tandis que les éléments de type target sont placés dans la colonne droite.

### Fonctionnalités interactives

Par défaut, l'apprenant peut:

- Créer des liens en cliquant successivement sur un élément source puis un élément cible
- Supprimer un lien existant en cliquant dessus
- Établir plusieurs connexions pour un même élément source ou cible

Pour désactiver cette interactivité (par exemple pour afficher une solution), utilisez la propriété disabled: true.

### Conseils de conception

Pour créer des exercices d'association efficaces:

Assurez-vous que les identifiants (id) sont uniques
Équilibrez le nombre d'éléments entre les colonnes source et cible
Utilisez le markdown dans la propriété content pour intégrer des formules, images ou mise en forme

`````ple
sandbox = "node"

// Initialisation du composant MatchList
matchList = :wc-match-list

// Définition des nœuds
especes = [
  { id: "loup", type: "source", content: "Loup" },
  { id: "ours", type: "source", content: "Ours" },
  { id: "renard", type: "source", content: "Renard" },
  { id: "aigle", type: "source", content: "Aigle royal" }
]

regimes = [
  { id: "carnivore", type: "target", content: "Carnivore" },
  { id: "omnivore", type: "target", content: "Omnivore" },
  { id: "charognard", type: "target", content: "Charognard" },
  { id: "rapace", type: "target", content: "Rapace" }
]

// Mélange des éléments au début de l'exercice
builder == #!lang=js

function shuffleArray(array) {
  for (let i = array.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [array[i], array[j]] = [array[j], array[i]];
  }
}

shuffleArray(especes);
shuffleArray(regimes);

matchList.nodes = [...especes, ...regimes];

statement==
Reliez chaque espèce à son régime alimentaire principal.
==

form==
{{ matchList }}
==

hint = [
  "Pensez aux proies typiques de chaque animal.",
  "Certains animaux ont un régime alimentaire très varié.",
  "\nSi vous êtes bloqué, essayez de commencer par les associations dont vous êtes le plus sûr."
]

grader== #!lang=js
grade = 0
feedback.type = "error"
feedback.content = "Mauvaise réponse"

let correctLinks = [
  { source: "loup", target: "carnivore" },
  { source: "ours", target: "omnivore" },
  { source: "renard", target: "omnivore" },
  { source: "aigle", target: "rapace" }
];

let userLinks = matchList.links;

// Vérification des réponses
let correctCount = 0;
for (let i = 0; i < correctLinks.length; i++) {
  let correctLink = correctLinks[i];
  for (let j = 0; j < userLinks.length; j++) {
    let userLink = userLinks[j];
    if (correctLink.source === userLink.source && correctLink.target === userLink.target) {
      correctCount++;
      break;
    }
  }
}

if (correctCount === correctLinks.length) {
  grade = 100
  feedback.type = "success"
  feedback.content = "Félicitations, toutes les associations sont correctes !"
} else {
  grade = (correctCount / correctLinks.length) * 100;
  feedback.type = "error";
  feedback.content = `Vous avez ${correctCount} associations correctes sur ${correctLinks.length}.`;
}
`````

`````ple
sandbox = "node"

liens = :wc-match-list

builder == #!lang=js
const paires = [['fr', 'France', 'Paris'], ['de', 'Allemagne', 'Berlin'], ['it', 'Italie', 'Rome'], ['es', 'Espagne', 'Madrid']]
// Chaque nœud a un identifiant unique ; les liens tracés relient un nœud source à un nœud cible.
liens.nodes = [
  ...paires.map(([id, pays]) => ({ id: 'pays-' + id, type: 'source', content: pays })),
  ...paires.map(([id, , ville]) => ({ id: 'ville-' + id, type: 'target', content: ville })).sort(() => Math.random() - 0.5)
]
attendus = paires.map(([id]) => ({ source: 'pays-' + id, target: 'ville-' + id }))
==

title ==
Relier pays et capitales
==

statement ==
Reliez chaque pays à sa capitale.
==

form ==
{{ liens }}
==

grader == #!lang=js
let corrects = 0
for (const lien of liens.links) {
  const ok = attendus.some((a) => a.source === lien.source && a.target === lien.target)
  if (ok) corrects++
  // Colore chaque lien selon sa justesse.
  lien.css = ok ? 'success-state' : 'error-state'
}
const faux = liens.links.length - corrects
grade = Math.max(0, Math.round((100 * (corrects - faux)) / attendus.length))
feedback.type = grade === 100 ? 'success' : 'error'
feedback.content = `${corrects} lien(s) correct(s), ${faux} lien(s) incorrect(s).`
`````
