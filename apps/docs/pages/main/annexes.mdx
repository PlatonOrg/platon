# Glossaire

| Terme                       | Définition                                                                                                                                                                                       |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Activité**                | Ressource qui enchaîne des exercices avec des règles (durée, tentatives, navigation…). Son code est dans `main.pla`. Voir [Activités](/main/resources/activities).                              |
| **Activité de cours**       | Copie d'une activité publiée dans une section de cours, avec ses propres dates, restrictions et paramètres. Voir [Ajouter des activités](/main/courses/activities).                            |
| **Builder**                 | 1. Script `builder` d'un exercice, exécuté une fois avant l'affichage pour préparer les données. 2. [Éditeur graphique](/main/resources/builder) qui personnalise un exercice créé à partir d'un modèle. |
| **CAS**                     | Service d'authentification centralisé d'un établissement, utilisable pour se connecter à PLaTon. Voir [Connexion CAS](/main/users/lti-integration#connexion-cas).                              |
| **Cercle**                  | Ressource qui regroupe d'autres ressources (sous-cercles, activités, exercices) et porte les droits d'écriture. Voir [Cercles](/main/resources/circles).                                        |
| **Cercle personnel**        | Cercle propre à chaque enseignant, visible uniquement par lui et les membres qu'il accepte.                                                                                                    |
| **Challenge**               | Activité de cours dont le classement est visible par tous les membres. Voir [Challenges](/main/courses/challenges).                                                                            |
| **Code de déblocage**       | Code de 6 caractères qui permet à un étudiant de reprendre un TP noté arrêté par une règle de sécurité.                                                                                        |
| **Composant**               | Élément interactif (`wc-…`) affiché dans un exercice : champ de saisie, QCM, éditeur de code, graphique… Voir [Composants](/components).                                                         |
| **Correcteur**              | Membre d'un cours chargé de corriger les copies d'une activité. Voir [Corriger les copies](/main/courses/corrections).                                                                          |
| **Correction**              | Note (et étiquettes, commentaires) attribuée manuellement par un correcteur ; elle remplace la note du grader.                                                                                  |
| **Cours**                   | Espace où un enseignant diffuse des activités à des membres. Voir [Gestion des cours](/main/courses/overview).                                                                                 |
| **Exercice**                | Ressource contenant une question et sa correction automatique. Son code est dans `main.ple`. Voir [Exercices](/main/resources/exercises).                                                       |
| **Exercice configurable / modèle (template)** | Exercice possédant un `main.plc`, dont les variables peuvent être personnalisées pour créer d'autres exercices. Voir [Rendre un exercice configurable](/main/programing/exercise/config). |
| **Feedback**                | Retour affiché après une validation, défini par le grader. Voir [Évaluation](/main/programing/exercise/grading).                                                                               |
| **Grader**                  | Script `grader` d'un exercice, exécuté à chaque validation pour lire la réponse et calculer la note.                                                                                            |
| **Graine (seed)**           | Nombre entre 0 et 99 fourni à chaque exercice pour rendre les tirages aléatoires reproductibles. Voir [Aléatoire et graine](/main/programing/exercise/workflow#aléatoire-et-graine-seed).       |
| **Groupe de cours**         | Sous-ensemble des étudiants d'un cours (TD, TP…). Voir [Gestion des groupes](/main/courses/groups).                                                                                             |
| **Groupe d'utilisateurs**   | Groupe de comptes géré par les administrateurs, inscriptible en bloc dans un cours. Voir [Groupes d'utilisateurs](/main/users/groups).                                                          |
| **LMS**                     | Plateforme d'enseignement de l'établissement (Moodle, Canvas…), reliée à PLaTon par LTI.                                                                                                        |
| **LTI**                     | Norme qui permet d'ouvrir PLaTon depuis un LMS avec connexion automatique. Voir [Intégration LTI](/main/users/lti-integration).                                                                 |
| **Navigation**              | Manière dont l'apprenant passe d'un exercice à l'autre dans une activité : progressive, composée, intelligente, par validation ou par les pairs. Voir [Configuration d'une activité](/main/programing/activity/config). |
| **Nunjucks**                | Langage de gabarits utilisé dans `statement`, `form`, `solution`, `hint` et `feedback` pour afficher des variables avec `{{ … }}`.                                                              |
| **Observateur**             | Utilisateur qui suit une ressource et reçoit des notifications. Voir [Observateurs](/main/resources/watchers).                                                                                 |
| **Période d'accès**         | Restriction d'une activité de cours qui donne des dates d'ouverture différentes selon les étudiants ou les groupes.                                                                            |
| **PLA, PLE, PLC, PLO**      | Fichiers `main.pla` (activité), `main.ple` (exercice), `main.plc` (configuration d'un modèle), `main.plo` (valeurs choisies pour un exercice issu d'un modèle). Voir [Fichiers d'un exercice](/main/programing/exercise/files). |
| **Player**                  | Partie de PLaTon qui affiche et fait jouer les exercices et les activités aux apprenants.                                                                                                       |
| **Prévisualisation**        | Exécution d'une ressource hors de tout cours, pour la tester.                                                                                                                                    |
| **Ressource**               | Terme générique désignant un cercle, une activité ou un exercice. Voir [Types de ressources](/main/resources/types).                                                                             |
| **Sandbox**                 | Environnement isolé où s'exécutent le builder et le grader : Node (JavaScript) ou Python.                                                                                                      |
| **Section**                 | Partie d'un cours regroupant des activités. Voir [Sections](/main/courses/sections).                                                                                                           |
| **Session**                 | Passage d'un apprenant sur une activité ou un exercice, avec ses réponses, ses tentatives et sa note.                                                                                          |
| **Statut**                  | État d'une ressource : brouillon, prêt à l'utilisation, besoin d'être testé, contient des bugs, ne pas utiliser.                                                                                |
| **Tentative**               | Validation d'un exercice ayant reçu une note supérieure ou égale à 0.                                                                                                                           |
| **Test d'entrée**           | Épreuve passée par des candidats sans compte, invités par e-mail. Voir [Tests d'entrée](/main/courses/tests).                                                                                  |
| **Topic, niveau**           | Tags qui classent les ressources par thème et par niveau d'études. Voir [Tags](/main/resources/tags).                                                                                          |
| **Version**                 | État figé d'une ressource ; `latest` désigne toujours la dernière version.                                                                                                                      |
