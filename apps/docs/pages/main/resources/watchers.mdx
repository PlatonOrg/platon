# Observateurs

Un **observateur** est un utilisateur qui **suit** une ressource : il est notifié de ses changements importants et peut
la retrouver facilement dans la recherche.

## Suivre une ressource

- Sur la page d'une ressource, cliquez sur **Suivre**. Le bouton devient **Ne plus suivre** pour arrêter.
- Vous suivez automatiquement les ressources que vous créez.
- Le nombre d'observateurs d'une ressource est affiché sur sa page **Vue d'ensemble**.

## Ce que vous recevez

Les observateurs d'une ressource reçoivent une notification, sauf pour les actions qu'ils ont faites eux-mêmes, lors
des [événements](/main/resources/events) suivants :

| Événement             | Exemple                                                                    |
| --------------------- | -------------------------------------------------------------------------- |
| **Nouvelle ressource** | Un exercice ou une activité est créé dans un cercle que vous suivez.       |
| **Nouveau status**    | Le [statut](/main/resources/types) de la ressource change (brouillon, prêt…). |
| **Nouveau membre**    | Un membre est ajouté au cercle.                                            |

<Callout type="info">
  Les demandes d'adhésion à un cercle (un utilisateur qui demande à devenir membre) sont envoyées aux
  **administrateurs**, qui peuvent les accepter. Un membre retiré d'un cercle est lui aussi notifié.
</Callout>
