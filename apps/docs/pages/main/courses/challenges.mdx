# Challenges

Un **challenge** est une activité de cours dont le **classement est visible par tous les membres du cours**. Il sert à
motiver les étudiants autour d'une activité ludique ou d'un défi.

## Créer un challenge

Un challenge s'ajoute comme n'importe quelle activité (voir [Ajouter des activités](/main/courses/activities)) : à
l'étape **Fonction** de l'assistant, choisissez **Challenge**.

Dès que le cours contient au moins un challenge, un onglet **Challenges** apparaît dans la page du cours. La carte
d'un challenge porte une icône de trophée qui mène à son classement.

## Les classements

L'onglet **Challenges** propose une liste déroulante **Activité** :

- **un challenge précis** : le classement des 100 premiers participants qui ont **réussi** l'activité (note de 100),
  dans l'ordre de réussite, avec la date à laquelle ils ont réussi ;
- **le classement général du cours** : les 100 utilisateurs qui ont le plus de points sur l'ensemble des challenges du
  cours. Pour chaque challenge, être premier rapporte 100 points, deuxième 99 points, et ainsi de suite jusqu'à 1 point
  pour la 100e place.

<Callout type="info">
  Seules les sessions réussies (note de 100) figurent dans les classements. Si une note a été modifiée lors d'une
  [correction](/main/courses/corrections), c'est la note corrigée qui est prise en compte.
</Callout>

Tant qu'aucun participant n'a réussi de challenge, l'onglet affiche un message d'attente ; un enseignant y trouve
aussi un bouton **Créer un challenge**.
