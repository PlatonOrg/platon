# Profil utilisateur

La page **Mon compte** s'ouvre depuis le menu de votre avatar, en haut à droite. Elle comporte deux onglets.

## À propos

| Champ                                 | Modifiable | Remarque                                                                                          |
| ------------------------------------- | :--------: | ------------------------------------------------------------------------------------------------- |
| **Prénom**, **Nom**, **Email**        |            | Fournis à la création du compte (par un administrateur ou par votre LMS).                         |
| **Rôle**                              |            | Administrateur, Enseignant ou Élève ; seul un administrateur peut le changer.                     |
| **Discord ID**                        |            | Identifiant du compte Discord associé, s'il y en a un.                                            |
| **Centre d'intérêt** (sujets, niveaux) |     ✔      | Topics et niveaux qui vous intéressent.                                                           |

Pour corriger votre nom ou votre adresse e-mail, adressez-vous à un administrateur de la plateforme, ou corrigez-les
dans votre LMS si votre compte a été créé par LTI.

## Sécurité : votre mot de passe

L'onglet **Sécurité** permet de **créer un mot de passe** (si votre compte n'en a pas encore, par exemple parce qu'il
a été créé par LTI ou CAS) ou de **modifier votre mot de passe** (le mot de passe actuel est alors demandé).

Le nouveau mot de passe doit contenir :

- au moins **12 caractères** ;
- au moins une **majuscule** et une **minuscule** ;
- au moins un **chiffre** ;
- au moins un **caractère spécial**.

<Callout type="info">
  Définir un mot de passe vous permet de vous connecter directement sur la page de connexion de PLaTon, avec votre nom
  d'utilisateur, en plus de l'accès depuis votre LMS.
</Callout>

## Gestion des comptes par les administrateurs

La création des comptes, le changement de rôle et l'activation ou la désactivation d'un compte se font dans
**Administration** › **Utilisateurs** : voir [Tableau de bord administrateur](/main/dashboard/admin). Un compte désactivé
ne peut plus se connecter tant qu'il n'est pas réactivé.
