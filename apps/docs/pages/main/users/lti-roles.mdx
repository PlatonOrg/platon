# Assignation des rôles via LTI

Lorsqu'un utilisateur arrive dans PLaTon depuis un LMS (voir [Intégration LTI](/main/users/lti-integration)), le LMS
transmet la liste de ses **rôles LTI** dans le cours d'où il vient. PLaTon s'en sert pour deux choses : le type de son
compte PLaTon et son rôle dans le cours PLaTon.

## Les deux familles de rôles

| Rôles LTI transmis par le LMS                                                                                                                                                                                                                   | Compte PLaTon   | Rôle dans le cours |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | ------------------ |
| **Rôles d'administration** (administrateur système, d'établissement ou de cours…) et **rôles d'enseignement** : `Instructor`, `Faculty`, `ContentDeveloper`, `Grader`, `TeachingAssistant`, `Lecturer`, `PrimaryInstructor`, `SecondaryInstructor`… | **Enseignant**  | **Enseignant**     |
| Tous les autres rôles (`Learner`, `Mentor`, `Member`, `Guest`…)                                                                                                                                                                                 | **Étudiant**    | **Étudiant**       |

Les rôles sont reconnus sous leur forme complète (par exemple
`http://purl.imsglobal.org/vocab/lis/v2/membership#Instructor`) comme sous leur forme courte (`Instructor`,
`Administrator`).

<Callout type="warning">
  Un rôle d'administrateur dans le LMS donne un compte **enseignant** dans PLaTon, jamais un compte administrateur.
  Le rôle administrateur PLaTon ne s'attribue que depuis **Administration** › **Utilisateurs**.
</Callout>

## Évolution des rôles au fil des connexions

- **Compte** : un compte étudiant est **promu enseignant** dès que l'utilisateur arrive avec un rôle enseignant. Un
  compte enseignant n'est jamais rétrogradé automatiquement.
- **Cours** : le rôle de l'utilisateur dans le cours PLaTon est **mis à jour à chaque lancement** pour correspondre à
  son rôle dans le LMS (dans les deux sens).

## Et les correcteurs ?

Le rôle de correcteur n'est pas transmis par LTI : il se définit dans PLaTon, activité par activité, parmi les membres
du cours (voir [Corriger les copies](/main/courses/corrections#qui-corrige-)).
