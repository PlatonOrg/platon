# Types de comptes

Chaque compte PLaTon a un **rôle** qui détermine les pages et les actions disponibles. Les droits sont **cumulatifs** :
un enseignant peut tout ce que peut un étudiant, et un administrateur tout ce que peut un enseignant.

| Rôle               | Ce qu'il permet                                                                                                                                                       | Comment le compte est créé                                                                                       |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Administrateur** | Tout ce que peut un enseignant, plus le menu **Administration** (utilisateurs, groupes, LMS, CAS, tags, annonces), l'accès à tous les cours, la création de cercles et la gestion des ressources des cercles partagés. | Par un autre administrateur, qui attribue le rôle depuis **Administration** › **Utilisateurs**.                 |
| **Enseignant**     | L'[espace de travail](/main/resources/types) (exercices, activités), la création de [cours](/main/courses/overview) et de [tests d'entrée](/main/courses/tests), la correction et le suivi des étudiants. | Par un administrateur, ou automatiquement par LTI pour un utilisateur ayant un rôle d'enseignant dans son LMS (voir [Rôles LTI](/main/users/lti-roles)). |
| **Étudiant**       | Les cours dont il est membre : lancer les activités ouvertes, consulter ses résultats et les commentaires de correction.                                              | Par un administrateur, ou automatiquement lors de la première connexion depuis un LMS.                            |
| **Démo**           | Comme un étudiant, dans le cours dont le lien d'accès démo a été ouvert. Compte anonyme sans mot de passe, supprimé après deux semaines d'inactivité.                 | Automatiquement, à l'ouverture d'un [lien d'accès démo](/main/courses/demo) par une personne non connectée.       |
| **Candidat**       | Passer le test d'entrée auquel il a été invité.                                                                                                                      | Par un enseignant, en ajoutant le candidat à un [test d'entrée](/main/courses/tests).                            |

<Callout type="info">
  Le rôle du compte est distinct du **rôle dans un cours** : un utilisateur ayant un compte enseignant peut être inscrit
  comme étudiant dans le cours d'un collègue. Seuls les comptes enseignant ou administrateur peuvent recevoir le rôle
  Enseignant dans un cours (voir [Membres d'un cours](/main/courses/members)).
</Callout>

## Changer le rôle d'un compte

Un administrateur change le rôle d'un compte dans **Administration** › **Utilisateurs**, depuis le menu de la ligne de
l'utilisateur (**Assigner le rôle Admin**, **Assigner le rôle Enseignant**, **Assigner le rôle Élève**). Le même menu
permet de **désactiver** un compte : il ne peut alors plus se connecter jusqu'à sa réactivation.
